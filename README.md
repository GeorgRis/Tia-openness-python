# Tia-openness-python

## Overview
Tia-openness-python is a project developed by Georg Risøy for Tratec Norcon(2024). The project aims to provide Python-based tools and scripts for automating Siemens TIA Portal using the TIA Portal Openness API. Many of the functions included are designed to streamline and automate tasks within TIA Portal.

## Features
- **Automation Scripts:** Scripts to automate common tasks in TIA Portal.
- **API Interaction:** Functions and examples on how to interact with TIA Portal Openness API.
- **Sample local web app:** Included in the program is a simple React site for easier usage


## Usage
1. Ensure you have TIA Portal installed and properly configured on your system.
2. You could also try the localhost for a user freindly
3. This is mainly out so that people could learn and se some python-based script using Openness


## API call Features
1. Starting TIA Portal
2. Openeing Project in TIA Portal
3. Creating devices (Includes kind of mapping for easier ordernumber)
4. Asigning IO-cards
5. Asigning ip-adress
6. Configure Network
7. Compiling
8. Setting attributes like PotenialGroup
9. Deleting device
10. Saving, close and dispose
